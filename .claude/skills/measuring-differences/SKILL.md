# 差を報告する前に

★**同一条件・別々の実行で対象語 Accuracy が約 0.30 pt ずれる。**
seed だけを変えた 3 本でも SD 0.11 pt。

**0.6 pt 未満の差は、反復するまで報告しない。**

→ [docs/pitfalls.md](../../../docs/pitfalls.md#r-24) R-24

## 実測されたばらつき

| | 対象語の SD |
|---|---|
| 同一条件・seed 3 本（同じマシン） | **0.11 pt** |
| 同一条件・別々の実行 | 約 **0.30 pt** |
| 遷移項あり・seed 3 本 | **0.44 pt** |

★**構成によってばらつき自体が変わる。** CRF の遷移項を入れると SD が 4 倍
（文一致では 9 倍）になった。**「良い seed を引いた結果」を効果と誤認する危険が
その構成では 4 倍大きい。**

## 手順

### 1. 差の大きさを見る

| 差 | 判断 |
|---|---|
| **2 pt 以上** | 報告してよい。ばらつきの 6 倍以上 |
| 0.6〜2 pt | **反復する。** 2 条件 × seed 3 本 |
| **0.6 pt 未満** | ★**反復なしで報告しない。** 「差は無い」とも「ある」とも言えない |

### 2. 反復する

```bash
for seed in 42 1337 2024; do
  uv run python scripts/train.py --config configs/<cfg>.yaml --device cuda \
    --seed $seed --train-path data/train_m5_split.jsonl --dev-path data/dev_r21.jsonl \
    --out-dir checkpoints/rep-<cfg>-$seed --metrics-out checkpoints/rep-<cfg>-$seed/metrics.json &
done
```

★**反復は高くない。** 16 vCPU のインスタンスで 6 本並列、約 2 時間・$0.2。
**1 本だけ回して 0.3 pt を報告するより、6 本回して「差は無い」と言うほうが速い。**

### 3. 平均と標準誤差で判断する

```
差 / 標準誤差 = |mean_b - mean_a| / (pooled_SD * sqrt(2/n))
```

| 値 | 判断 |
|---|---|
| **2 以上** | 差があると言ってよい |
| 2 未満 | **検出できない。** n=3 で検出できるのは約 0.8 pt 以上 |

★**「検出できない」と「効果が無い」は違う。** 小さい効果は残っているかもしれない。
言えるのは「**この大きさの効果は無い**」まで。

## ★決定的な比較（反復が要らない場合）

**同じモデルの出力に対して、比較のしかただけを変えた場合は反復が要らない。**

例: 四つ仮名を `phonetic_key` に入れて +0.24 pt。
これは**同じ予測を別の基準で数え直しただけ**なので、ばらつきが無い。

| 種類 | 反復 |
|---|---|
| 学習をやり直す（データ・構成・seed が変わる） | ★**要る** |
| 評価コード・正規化・ラベルだけ変える | 要らない |
| 推論時のパラメータだけ変える（同じ checkpoint） | 要らない |

★**M7 の連接行列（N − N0 = +1.55 / +1.30 / +1.35）はこの形で判定した。**
同じ checkpoint のスコアに行列を足すかどうかだけなので、seed 3 本の**対応のある差**が
3 本とも同じ向きかを見れば足りる。差の標準誤差は、2 つの出力が食い違った件数から出せる:

```
差 / SE:  SE = sqrt((直った + 壊れた) / n − 差²) / sqrt(n)     # n = 件数、差は割合
```

⚠️ **INT8 の数字は「決定的」ではなかった**（R-26）。読みキャッシュと動的量子化のせいで、
**評価の順序によって同じ文のスコアが変わる**（精度への影響は 0.01 pt 程度）。
決定的な比較は、**同じスコアを共有して**行うか、FP32 で突き合わせること。

## 生き残っている結論と、無効になった報告

**生き残る**（ばらつきの 3 倍以上）:

| | 大きさ |
|---|---|
| 辞書事前分布 | **+4.25 pt** |
| Hard Set の数詞 | **+19.64 pt** |
| 四つ仮名 | +0.24 pt（★決定的な比較） |
| 事前学習エンコーダの文一致 | +2.66 pt |
| OpenJTalk との差 | **−2.5 pt** |
| カーブが平坦（2〜13M） | ★差がばらつき以下 = それが結論 |
| 連接行列（ニューラルに足す, M7） | **+1.40 pt**（★決定的・seed 3 本とも正） |
| ニューラルは辞書 + 行列に足さない（M7） | −0.13 pt ★差がばらつき以下 = それが結論 |
| 重複排除で品詞を失う損失（M7） | **+1.18 pt**（★決定的・差 / SE 10.8） |

**無効**（1 本ずつの比較で 0.6 pt 未満）:

```
数詞増量 −0.28 / ルビ事前学習 −0.06 / size-s が最良 +0.36
size-l が最低 −0.59 / 事前学習エンコーダ +0.52（対象語）
CRF の遷移項 +0.32（反復後 +0.07、SE 0.28）
```

## なぜばらつくか

| | |
|---|---|
| GPU の非決定性 | 同じ seed でも演算順序が揺れる |
| **dev が 367 件** | best 選択のばらつきが大きい |
| **best 選択そのもの** | 揺れた dev 曲線の最大値を拾うので、ばらつきを増幅する |

★**dev を増やせばばらつきは下がる**が、未検証。
