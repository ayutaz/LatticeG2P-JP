# 数詞 + 助数詞の例文生成プロンプト v1.0

`scripts/make_numeral_batches.py` が作った `data/batches_num/batch_NNN.jsonl` を
サブエージェントに渡すときのプロンプト。`NNN` を差し替えて使う。

**M2 の生成プロンプト（`subagent-generate-v1.md`）と違い、読みを検証させない。**
読みは事前に作った表で確定しており、エージェントの仕事は
「その読みになる自然な文を書き、文全体の読みを正確に書き起こす」ことだけ。

**なぜ分けるか**: 数詞 + 助数詞の音便（`三本→サンボン`）は
ラティス整合フィルタで検出できない。`本` には `ホン` も `ボン` も辞書にあるので、
`サンホン` と書かれても機械的には通ってしまう。
**知識（小さい表・高品質）と量（文・安価）を分離する。**

---

日本語 G2P（漢字の読み推定）の学習データを生成するタスクです。

# 入力
`data/batches_num/batch_NNN.jsonl` を読んでください。
各行は `{"surface": "三本", "reading": "サンボン"}` です。

# やること

各行について、**その表記がその読みで読まれる自然な現代日本語の文を 4 文**作ってください。

★**読みは既に決まっています。判断しないでください。**
`三本` が `サンボン` と書いてあるなら、文中の `三本` は必ず `サンボン` と読まれる
文脈にしてください。別の読みになる文（例: `三本木` という地名）は書かないでください。

# 出力形式

`data/batches_num/batch_NNN.out.jsonl` に
1 行 1 文の JSONL で書いてください。

```json
{"text": "机の上に鉛筆が三本ある", "reading": "ツクエノウエニエンピツガサンボンアル", "target_surface": "三本", "target_reading": "サンボン", "target_start": 9}
```

# ★読みの表記規則（最重要）

- すべて全角カタカナで書く
- **助詞の「は」は ワ**（「私は」→ ワタシワ）
- **助詞の「へ」は エ**（「家へ」→ イエエ）
- **助詞の「を」は ヲ**（「本を」→ ホンヲ）
- **長音は表記どおり**（「東京」は トウキョウ。トーキョー とは書かない）
- 促音「ッ」、拗音「ャュョ」、撥音「ン」を省略しない
- 空白・句読点は読みに入れない

# ★この課題に固有の禁止事項

1. **`四`・`六`・`八` を文のどこにも使わないこと。**
   これらは評価用に取り分けてある語で、学習データに入れると評価が無効になります。
2. **算用数字を使わないこと**（3 本 ではなく 三本）。
3. 対象の数詞 + 助数詞**以外**の漢数字も使わないこと。
4. アルファベット・固有名詞（人名・地名・企業名）を含めないこと。
5. 記号は句読点のみ。

# 文の要件

- 文の長さは 10〜35 文字程度
- 文体と話題を多様にする（すべて「〜です。」で終わらせない）
- 対象語の出現位置も多様にする（文頭・文中・文末）
- **日常的で自然な文にする**。数を数える場面は身近にいくらでもあります

# 品質について

`reading` は機械的に検証されます。**文全体の読みを一字一句正確に**書いてください。
送り仮名や助詞を読み飛ばさない、連濁を正しく反映する、が要点です。

自信が持てない文は書かないでください。数より正確さが重要です。

終わったら、書き出した文の数を報告してください。

---

## 設計意図

| 指示 | 理由 |
|---|---|
| 読みを検証させない | 音便はラティス整合フィルタで検出できない。表で確定させる |
| 四・六・八 を禁止 | dev の held-out 語。文中に出るだけで読みが教えられる（→ docs/pitfalls.md R-20） |
| 4 文ずつ | M2 と同じ。1 読みあたりの文数を揃える |
